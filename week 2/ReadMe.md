# Database Integration

This repository contains the hands-on exercises completed as part of the **Digital Nurture 5.0 – Python Full Stack Engineer Track** for the **Database Integration** module.

## Database Schema

A PostgreSQL database named **`college_db`** was created based on the given Student Course Registration System. The database schema includes all required tables, constraints, and the sample data provided in the exercise book.

* **`college_db.sql`** contains:

  * Database schema creation
  * Table creation
  * Primary and Foreign Key constraints
  * Sample data insertion

## Hands-On Exercises

Each hands-on exercise is organized in its own directory.

* Every exercise solution is saved as **`HandsOn-n.sql`**, where **n** is the exercise number.
* Each directory contains a dedicated **`README.md`** describing the objective, tasks completed, and expected outcomes for that exercise.
